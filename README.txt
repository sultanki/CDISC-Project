SDTM hands-on notebook

Files
- SDTM_hands_on.ipynb  the notebook (run this one)
- dm.csv ae.csv cm.csv ex.csv vs.csv lb.csv  sample SDTM data from the public CDISC pilot study (CDISCPILOT01), via the PHUSE scripts repository. lb.csv keeps 7 lab tests only.
- SDTM_hands_on_preview.html  read-only copy with all answers already run

How to run
Option A (Google Colab, no install): upload the notebook and all six CSV files to a new Colab session (Files panel, upload), then Runtime > Run all.
Option B (your computer): pip install jupyter pandas, put all files in one folder, run "jupyter notebook", open SDTM_hands_on.ipynb.

Work through the "Try it" boxes first, then run the Solution cell below each one.
